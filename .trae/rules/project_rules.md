# DevPrompt AI · 项目规则（Trae）

## 强制规则：先读宪法，再执行任何任务

**`AGENTS.md`（位于项目根目录）是本项目唯一的 Agent 宪法，优先级高于一切其他规则与文档。**

在执行任何任务（写代码、改代码、跑命令、回答项目相关问题）之前，必须：

1. **首先阅读并加载 `AGENTS.md` 全文**，确认理解其 MUST（必须遵守）/ SHOULD（建议遵守）条目
2. **按宪法 MUST-01 执行**：实现类任务先读对应文档章节，能说出任务对应的 F-xxx 编号才动手
3. **按宪法 MUST-02 执行三阶段自检**：输入校验 → 处理逻辑 → 输出验证，任一不过不得进入下一阶段，结果必须显式报告
4. **规则冲突时**：`AGENTS.md` > 项目架构文档 > 功能清单 > 技术栈文档 > 一般工程惯例；宪法与代码现状冲突时以代码为准并立即上报

## 宪法要点速查（详见 AGENTS.md 原文）

| 编号 | 核心约束 |
|---|---|
| MUST-04 | 优先原生能力，新增第三方依赖是最后手段 |
| MUST-06 | 四层依赖严格单向，`domain/` 纯逻辑无 I/O，仅经 Protocol |
| MUST-08 | 业务判定只允许在指定位置，前端零阈值常量 |
| MUST-09 | ripgrep 先压 ≤25 条候选，决策层再排序，顺序不可颠倒 |
| MUST-13 | 异步路径禁阻塞调用，一律 `asyncio.create_subprocess_exec` |
| MUST-14 | 缓存键必须含阈值配置 hash |
| MUST-19/20 | 密钥不入库不进日志；路径穿越防护 |
| MUST-21 | 提交规范 `type(scope): subject`，body 写为什么 |
| MUST-25 | W1 生死线优先于一切：候选集召回率 ≥80% 才可进入 W2（✅ 已通过：95%） |
| MUST-26 | 反问由具体未知驱动、无轮次上限；软护栏（≥10 轮/超成本）必须显式裁决；用户可随时逃生「直接生成」 |
| MUST-29 | CI 门禁：Ruff / mypy / pytest / tsc / 架构约束 / 契约冒烟 |
