## 三、总体设计

```
设置中心
└─ 可观测性（新标签）
   ├─ 左栏：会话列表（搜索 / 项目筛选 / 加载更多）
   └─ 右栏：子标签
      ├─ Session Log：按轮台账 + 搜索 + 类型筛选 + 折叠 + 检查器 + 导出
      └─ Trace Metrics Replay：KPI + 图表 + 时间轴 + 播放控制 + 导出
```

数据流：

```
GET /api/v1/sessions/{id}/observability?before=&limit=
  → 服务层校验归属 + 读取轮次（含 steps/sensorium/usage）
  → EventStore 读取一页事件（台账用）+ 最近 N 条事件（指标用）
  → domain/observability/trace_metrics.py 纯函数聚合
  → 返回 {turns, events, metrics, last_seq, has_more_events, next_before}

前端 useSessionObservability
  ├─ 初始加载 → 两个子模块共享同一份数据
  ├─ loadOlder() 用 next_before 向前补事件
  ├─ 实时跟随（可选）复用 GET /sessions/{id}/stream?since=N，按 seq 去重追加
  └─ 导出：当前筛选结果 JSON / CSV（浏览器下载）
```

## 四、后端改动

### 4.1 新增领域纯函数

**新增** `src/devprompt_ai/domain/observability/__init__.py`（空导出）
**新增** `src/devprompt_ai/domain/observability/trace_metrics.py`

职责：只接收 `Sequence[RunEvent]` + `Sequence[TurnRecord]`，输出 `TraceMetrics` 数据类，零 I/O、零 LLM、零阈值判断（MUST-06/MUST-08）。

```python
@dataclass(frozen=True, slots=True)
class TraceMetrics:
    event_total: int
    counts: dict[str, int]                 # 事件类型分布
    wall_clock_ms: int | None              # 首末有效 ts 差；无 ts 为 None
    action_total: int
    action_failed: int
    action_p50_ms: int | None
    action_p95_ms: int | None
    action_max_ms: int | None
    token_total: int
    token_series: tuple[tuple[int, int], ...]       # (turn_index, llm_tokens)
    sensorium_series: tuple[dict[str, float], ...]  # 来自 turn.summary["sensorium"]
    phases: tuple[dict[str, object], ...]           # phase 事件区间
    timeline: tuple[dict[str, object], ...]         # 逐事件轻量投影
    quality: dict[str, object]                      # timestamps/events_truncated/timeline_truncated

def compute_trace_metrics(
    events: Sequence[RunEvent], turns: Sequence[TurnRecord], *,
    event_cap: int = 5000, timeline_limit: int = 2000,
) -> TraceMetrics: ...
```

实现要点（全部确定性）：
- `counts`：`collections.Counter(event.type)`。
- `action_*`：取 `event.type == "action"` 且 `data.duration_ms` 为整数；p50/p95 用排序后线性插值（与 `scripts/measure_sensorium.py:52-60` 同口径），空集记 `None`。
- `token_*`：`turn.usage["llm_tokens"]`（非负整数）；`token_total = sum`。
- `sensorium_series`：白名单键 `momentum/pressure/coverage/complexity/familiarity/stability/score`，非数值丢弃。
- `phases`：按 `type == "phase"` 的 `data.phase` 聚合连续区间（start_seq/end_seq/事件数）；无 phase 事件为空数组。
- `timeline`：逐事件 `{seq, ts, type, run_id, label, phase, duration_ms}`；`label` 取 action.title / phase / stop.status / error.code / type；超过 `timeline_limit` 时等距抽样并置 `quality.timeline_truncated=True`。
- 时间解析：只接受 `"%Y-%m-%d %H:%M:%S"`（SQLite UTC）与 ISO8601；失败返回 None，`quality.timestamps` 记 `measured/partial/missing`，**不猜时间**（MUST-11d）。

### 4.2 新增只读端点

**修改** `src/devprompt_ai/interfaces/api/schemas.py`：新增契约模型（Pydantic v2，字段全必填/带明确默认）：

- `ObservabilityEventPayload {seq:int, type:str, run_id:str="", data:dict[str,Any], ts:str=""}`
- `ObservabilityTurnPayload {turn_id, turn_index, state, created_at, input, target, conclusion, open_items:list[str], steps:list[dict], facts:list[dict], llm_tokens:int=0, sensorium:dict[str,float], claims:dict[str,Any]}`
- `TraceTimelinePointPayload {seq:int, ts:str, type:str, run_id:str, label:str, phase:str, duration_ms:int|None}`
- `TraceMetricsPayload {event_total, counts:dict[str,int], wall_clock_ms:int|None, action_total, action_failed, action_p50_ms, action_p95_ms, action_max_ms, token_total, token_series:list[list[int]], sensorium_series:list[dict[str,float]], phases:list[dict], timeline:list[TraceTimelinePointPayload], quality:dict}`
- `SessionObservabilityPayload {session_id, events:list[ObservabilityEventPayload], has_more_events:bool, next_before:int, last_seq:int, turns:list[ObservabilityTurnPayload], metrics:TraceMetricsPayload}`

**新增** `src/devprompt_ai/interfaces/api/observability_routes.py`

```python
router = APIRouter(prefix="/api/v1", tags=["observability"])

@router.get("/sessions/{session_id}/observability", response_model=ApiResponse[SessionObservabilityPayload])
async def get_session_observability(
    session_id: str,
    before: int = Query(1 << 30, ge=1),
    limit: int = Query(200, ge=1, le=500),
) -> ApiResponse[SessionObservabilityPayload]: ...
```

实现（薄壳，只做取值与装配）：
1. `bundle = await _bundle()`（复用 `runtime_routes._bundle`，避免重复装配）。
2. `turns = await bundle.service.list_turns(_USER_ID, session_id, limit=_TURN_CAP)` —— 复用 `_load_owned` 的 6003 归属校验；`_TURN_CAP = 500`。
3. `page = await bundle.bus.history_before(session_id, before, limit=limit)`。
4. `all_events = await bundle.events.since(session_id, 0, limit=_EVENT_CAP)`（`_EVENT_CAP = 5000`，指标口径）。
5. `last_seq = await bundle.bus.last_seq(session_id)`。
6. `metrics = compute_trace_metrics(all_events, turns)`；映射为响应模型。
7. 分页语义：`has_more_events = len(page) == limit and page[0].seq > 1`；`next_before = page[0].seq if has_more_events else 0`。
8. `quality.events_truncated = len(all_events) >= _EVENT_CAP`。

**修改** `src/devprompt_ai/interfaces/api/app.py:180-181`：注册 `observability_routes.router`。

**契约冻结**：运行 `uv run python scripts/export-openapi.py` 更新 `openapi.json`；`tests/api/test_openapi.py` 会校验导出物一致。

## 六、交互规格

### 6.1 Session Log（对标 ui-trajectory）

1. **会话列表**：搜索（标题/项目，客户端过滤已加载页）、项目下拉（来自已加载项）、`加载更多`；选中项左侧 2px 主色竖线（复用 `settings-nav__item--active` 语言）。
2. **台账分组**：按轮分组，轮头显示 `#index · state · 时间 · tokens · facts 通过数`；组内记录顺序：User → Thought → Action(Tool) → Assistant → 边界（stop/error）。
3. **工具栏**：搜索（匹配 input/conclusion/action title/detail/output/phase/error）、折叠全部轮次、折叠全部工具调用、实时跟随（开关）、刷新、导出。
4. **加载更早**：首行 `加载更早` 按钮 → `before=next_before`；按钮显示加载中，不改变滚动位置（保持可视锚点）。
5. **虚拟行**：固定行高 44px + overscan 8；行内容单行截断（`-webkit-line-clamp` 仅用于双行摘要）；点击行打开右侧检查器（不在行内展开，保证固定行高）。
6. **实时跟随**：开关打开且 `last_seq>0` 时订阅 `openSessionStream(sessionId, lastSeq)`；按 seq 去重追加；用户向上滚动即暂停跟随并显示「回到最新」；收到 `stop/error` 自动关闭开关。
7. **导出**：
   - `导出当前结果`：当前筛选后的记录 → JSON / CSV。
   - `导出全部`：循环 `loadOlder()`（上限 10 页 / 2000 条，超限提示）后导出。
   - JSON 结构：`{session_id, exported_at, filters, records}`；CSV 列：`seq,ts,turn_index,type,label,phase,duration_ms,text`。
8. **空态**：无会话 / 会话无事件（旧会话）时分别给出说明，不伪造数据。

### 6.2 Trace Metrics Replay（指标可视化 + 回放）

1. **KPI 卡片**：事件总数、动作数、失败动作、Token 总量、墙钟时长、动作 p50/p95。
2. **图表**（全部 SVG/CSS，无新依赖）：
   - 事件类型分布：横向条形（Top 8）。
   - 动作耗时：Top 10 最慢动作横条 + p50/p95 标注。
   - Token 序列：按 turn_index 的折线/面积图。
   - 六维雷达：`momentum/pressure/coverage/complexity/familiarity/stability` 多边形；`score` 单独显示。
3. **时间轴**：
   - 横轴按 seq 比例投影；每个事件一个块，按类型着色（展示映射，非业务判定）。
   - hover 显示 `seq / ts / type / label / duration`。
   - 单击：把播放游标定位到该事件；拖动：选择区间（过滤下方事件列表与台账高亮）；滚轮：缩放时间窗；右键单击：清除区间；右键拖拽：平移已缩放视窗。
   - 键盘：`role="slider"`，左右方向键 ±1 事件，Home/End 跳首尾。
4. **回放控制**：播放/暂停、重播、上一步/下一步、速度（0.5/1/2/4x，基准 2 事件/秒）、进度 `seq / total`；播放到末尾自动暂停；游标事件在下方「当前记录」卡展示。
5. **筛选**：事件类型多选 chips + 文本搜索（匹配 payload JSON 字符串）+ 时间轴区间；筛选只影响列表/时间轴高亮，KPI 保留整会话口径并在标题旁标注「未随筛选变化」。
6. **数据质量披露**：`quality.events_truncated` / `timeline_truncated` / `timestamps != measured` 用一行提示展示，不静默。
7. **导出**：指标 + 时间轴 + 当前筛选事件 → JSON；时间轴行 → CSV。
8. **与日志联动**：当前记录卡的「在 Session Log 中查看」按钮 → 切换子标签并选中对应 seq。

### 6.3 响应式

- `≥1100px`：左栏 260px + 右栏自适应。
- `860–1099px`：左栏 220px；图表两列变一列。
- `<860px`：会话列表折叠为顶部下拉/抽屉；台账与检查器上下堆叠；时间轴高度 48px；工具栏换行。
- 所有滚动容器设置 `min-height: 0`，避免 flex 溢出。

### 7.3 手工验收

1. 启动后端与前端，打开设置 → 可观测性。
2. 选一个真实会话（例如 3 轮 E2E 留下的会话）：验证台账分组、搜索、折叠、加载更早、检查器。
3. 打开实时跟随，另起一轮任务：新事件应逐条追加，停止后开关自动关闭。
4. Trace Replay：播放/暂停/步进/速度、拖选区间、滚轮缩放、右键清除、导出 JSON/CSV。
5. 用一条无事件的历史会话验证降级文案（仅轮次、无指标）。
6. 窗口缩到 800px 验证响应式布局。

## 八、假设与决策

| # | 决策 | 理由 |
|---|---|---|
| D1 | Harness 仅作**交互与信息架构**参考，不复制代码 | 其实现依赖 133KB 的 TrajectoryTable 与私有 UI 包；本项目技术栈/数据模型不同 |
| D2 | 新增 1 个只读端点，而不是前端多次拉 `/events` 拼指标 | 指标聚合需要整会话口径；服务端一次读取 + 纯函数计算，避免前端 N 次分页 |
| D3 | 指标用服务端快照，实时事件只追加台账 | 避免前端重复实现聚合；Live 时显示「刷新指标」入口 |
| D4 | 回放是**纯视觉回放**，绝不重跑 run/LLM | 避免副作用与费用；符合“观测”语义 |
| D5 | 台账行固定 44px + 检查器侧栏 | 固定行高才能无依赖虚拟化；展开内容放检查器，避免行高抖动 |
| D6 | 导出“当前筛选结果”与“全部（上限 2000 条）”两档 | 全量导出可能触发大量分页；上限与提示保证可控 |
| D7 | 全量新文案双语，键集合由 `i18n/keys.test.ts` 守卫 | 项目现有约定 |
| D8 | 不新增依赖：图表用 SVG/CSS，下载用 Blob + `<a download>` | MUST-04；当前依赖表已足够 |
| D9 | 事件与轮次按时间窗归组，无法归组的事件放「当前/未归属」组 | 事件无 turn_id；时间窗是唯一现有可对齐信号，且缺失时如实分组 |
| D10 | 端点返回 `input`（用户原句） | 该端点仅本人可读，与 `GET /turns/{id}` 现有口径一致；不写日志（MUST-19） |

## 九、风险与应对

| 风险 | 应对 |
|---|---|
| 旧会话没有 `run_events` | 台账退回轮次视图；指标显示 `no_data`，不伪造 |
| 事件 payload 过大 | 复用 `harness/trace.py` 已脱敏/截断（≤2000 字符）的 action output；分页默认 200、上限 500 |
| 时间戳为本地/UTC 混用 | 只按同一 SQLite 格式解析；解析失败记 `partial/missing`，墙钟时长不展示 |
| 长会话虚拟行高度误差 | 固定行高 + 检查器侧栏；折叠组不参与虚拟列表 |
| 契约漂移 | `export-openapi.py` + `pnpm gen:contract` + `tests/api/test_openapi.py` 三闸 |
