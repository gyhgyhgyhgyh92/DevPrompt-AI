# 页内文件资源管理器复刻（Win11 风格）实施计划

> 版本 v1.0 · 2026-10-13 · 状态：待用户批准
> 来源：项目所有者 /plan 指令（「将文件选择/浏览弹窗升级为浏览器页面内嵌入的原生文件资源管理器界面」）+
> 3 项 AskUserQuestion 裁定（高保真复刻 Win11 / 保留模态容器 / 目录+文件+元数据）。
> 基线：提交 f949121（页内简化浏览器 + `GET /project/browse`）。

---

## 一、Summary（目标与结论）

将现有 `FolderPickerModal`（简化列表：仅目录、单列表、返回上级）**升级为 Windows 11 资源管理器高保真复刻界面**：地址栏面包屑（可点击跳转）、前进/后退/上级导航、详情列表（名称/修改日期/类型/大小四列，目录+文件）、状态栏计数。**完全保留现有数据流**（`GET /project/browse` 前端服务端分层、hook/调用路径）**与既有交互**（模态开合、Esc、焦点管理、「选择当前文件夹」确认语义、ConsoleInput 接线零改动）。

**核心技术边界（已向用户说明并获认可）**：浏览器安全沙箱无法嵌入真实 explorer.exe 窗口；本方案为 HTML/CSS 高保真复刻——界面渲染于页面 DOM 内，数据由本机后端供给。

**明确不做**：不作真实 OS 窗口嵌入尝试；不新增第三方依赖（图标为自绘 SVG）；不做列排序交互、右键菜单、多选、新建文件夹（本地浏览只读定位）。

## 三、Proposed Changes（按执行顺序）

### 阶段 A · 后端（harness + 契约）

**A1. `src/devprompt_ai/harness/browse.py`**
- `BrowseEntry` 增字段：`kind: str`（`"dir"` / `"file"`，必填）、`size: int | None = None`、`modified_at: str | None = None`。
- 新增 `_iter_entries(root) -> list[BrowseEntry]` 替换 `_iter_subdir_names`：
  - `os.scandir` 逐条目：`entry.is_dir()` 判定；`entry.stat()` 取 `st_size`/`st_mtime`（Windows 上 DirEntry.stat 数据来自目录扫描、无额外系统调用）；
  - `modified_at = datetime.fromtimestamp(st.st_mtime).isoformat(timespec="seconds")`（本地时间，naive ISO——同机工具无需时区换算）；
  - 目录 `size=None`（资源管理器不展示目录大小）；单条目 `OSError` 跳过（沿用现防御）；
  - 排序：**目录（名称升序）+ 文件（名称升序）**（`key=lambda e: e.name.lower()`）。
- `_list_subdirs_sync` 改名/改造为 `_list_entries_sync`（列全条目；截断与 2001/2002 逻辑不变）。
- `_list_drives_sync`：条目 `kind="dir"`（其余字段 None）。
- 模块 docstring 同步（不再「仅列目录」）。

**A2. `interfaces/api/schemas.py`** — `BrowseEntryPayload` 增：
```python
kind: Literal["dir", "file"]
size: int | None
modified_at: str | None
```
（无默认值；`Literal` 已在该文件使用。）

**A3. `interfaces/api/routes.py`** — `get_project_browse` 映射处补 `kind=e.kind, size=e.size, modified_at=e.modified_at`。

**A4. 契约重生成**：`uv run python scripts/export-openapi.py`（13 路径/16 操作不变，`BrowseEntryPayload` schema 变更）。

### 阶段 C · 前端组件重写（核心）

**C0. 契约同步**：`pnpm gen:contract`（openapi.generated.ts）→ `schemas/common.ts` 的 `BrowseEntryPayloadSchema` 增 `kind: z.enum(['dir','file'])`、`size: z.number().nullable()`、`modified_at: z.string().nullable()`。`endpoints.ts` 零改动。

**C1. `FolderPickerModal.tsx` 重写 UI（保留骨架）**：

保留：props（`open/initialPath/onSelect/onClose`）、三 effect（焦点/Esc/初始加载）、`navigate()` 加载模式（loading/error/保持旧视图）、`canConfirm`（`path !== ''`）、`role="dialog" aria-modal aria-label="选择项目文件夹（本地）"`。

新增结构与逻辑：

1. **导航历史栈**（10 行内）：`history: string[]` + `cursor: number`（均 useState）。
   - `navigateTo(path)`：截断 `cursor` 之后的项 → push → cursor 指向新项 → 触发加载；
   - 后退 `cursor-1`、前进 `cursor+1`、上级用 `listing.parent`（`null` 禁用；`""` = 回驱动器列表）；
   - 漂移分支：初始加载（open/initialPath 变化）重置 `history=[initialPath]`、`cursor=0`。
2. **导航工具行**：`↑`（aria-label="返回上级"）、`←`（"后退"，`cursor<=0` 禁用）、`→`（"前进"）+ **地址栏面包屑**：
   - 分段（纯展示）：`path===''` → 单段「此电脑」；否则 `['此电脑', ...path.split(/[\\/]+/).filter(Boolean)]`（`D:\Works\AI` → `['此电脑','D:','Works','AI']`）；
   - 每段按钮可点击跳转：`此电脑`→`''`；`D:`→`D:\`；其余按序用 `'\\'` 拼接累积路径；
   - 末段为当前位置（非链接样式）。
3. **详情列表**：
   - 列头行：`名称 | 修改日期 | 类型 | 大小`（CSS grid `2fr 1.1fr 0.9fr 0.6fr`）；
   - 行：图标（目录复用现有 `FolderIcon` SVG；文件新增 `FileIcon` 内联 SVG）+ 名称 + `formatDateTime(modified_at)` + 类型列（目录→「文件夹」；文件→`后缀大写 + ' 文件'`，无后缀→「文件」）+ `formatSize(size)`（目录留空）；
   - **工具函数**（模块级纯函数）：`formatSize(bytes)`（B/KB/MB/GB，1024 进制 1 位小数）、`formatDateTime(iso)`（字符串切分→`YYYY/MM/DD HH:mm`，**不走 Date 解析**避免时区歧义）、`fileKindLabel(name)`；
   - 交互：**单击 = 选中**（行浅色高亮 `selectedPath` state；Win11 语义）+ **双击目录 = 进入**；**文件行双击无动作**（只读）；**键盘 Enter**（行聚焦时，目录进入）；
   - **触屏兼容**：`const isCoarsePointer = window.matchMedia('(pointer: coarse)').matches`（jsdom 无 matchMedia 时兜底 false）；coarse 时**单击即进入目录**（文件单击仅选中）；鼠标语义下单击仅选中；
   - 空态「此文件夹为空」、加载中、错误（文案不变）。
4. **状态栏 + 底部**：左「N 个项目」；右「取消」+「选择当前文件夹」（语义与禁用条件不变）。
5. 面包屑/路径过长：`text-overflow: ellipsis`（面包屑末段 flex 收缩）。

**C2. `FolderPickerModal.css` 重写**：宽度 `min(880px, 100%)`；工具栏（`--color-surface-code` 底？——**决定：白底 + `--divider` 分隔**，保持与设置模态同基调）；列表行高 32px、hover `--hover`、选中 `--color-primary-100`（品牌浅绿——沿用应用品牌色而非 Win11 蓝，保持应用视觉一致性）；列头 `--color-text-muted` 小字 + 底线；
**响应式**：≤768px 隐藏「修改日期」「类型」列（grid 改 `1fr 0.6fr`）；≤480px 仅「名称」列；状态栏在窄屏隐藏。**不新增 token**。

**C3. `ConsoleInput.tsx` / `ConsoleInput.css`：零改动。**（文件选择器入口、校验链路、样式均不变。）

## 四、Assumptions & Decisions（决策台账——执行者无需再做选择）

| # | 决策 | 依据 |
|---|---|---|
| 1 | 「原生」以高保真复刻实现（HTML/CSS），不尝试真实窗口嵌入 | 用户 AskUserQuestion 裁定（浏览器硬边界已说明） |
| 2 | 保留模态容器（overlay 卡片），仅升级内部 UI | 用户裁定；交互路径（按钮→模态）不变 |
| 3 | 显示目录 + 文件 + 元数据（文件只读） | 用户裁定 |
| 4 | **文件仅展示不可进入**：双击/单击（触屏）文件无导航、无选择动作（选中高亮可有） | 本交互目的为选文件夹；避免「选文件」语义歧义 |
| 5 | 「选择当前文件夹」语义不变（= 确认当前所在目录）；不做「选中文件夹行再确认」的模式切换 | 最小改动 + 与现有文案/测试语义一致 |
| 6 | 选中/焦点色用项目品牌色系（`--color-primary-100`）而非 Win11 蓝 | 应用整体品牌为绿色，保持视觉一致性；结构布局仿 Win11 |
| 7 | 不新增第三方依赖；目录/文件图标为内联 SVG | MUST-04 |
| 8 | 排序在后端（目录在前、名称升序）；前端不做排序交互（列头不可点） | MUST-08 精神（业务/数据秩序由后端定）；控制范围 |
| 9 | 前端日期格式化不走 `Date` 解析（字符串切分），避免时区偏移 | 后端已输出本地 ISO，直接切分最稳 |
| 10 | 触屏（coarse pointer）单击=进入目录；鼠标单击=选中、双击=进入 | 触屏无 dblclick；`matchMedia('(pointer: coarse)')` 为标准 API |
| 11 | 组件名保持 `FolderPickerModal`（不改名） | 最小改动（改名连锁 import/测试/文档） |
| 12 | 契约 additive（entry 2→5 字段），13 路径/16 操作计数不变；前端同笔切换无兼容窗口 | 本地工具单消费者 |
| 13 | 元数据取 `st_size`（B 字节）与 `st_mtime`（本地 ISO 秒精度） | Windows DirEntry.stat 免费；秒精度足够列表展示 |

## 六、风险与缓解

| 风险 | 缓解 |
|---|---|
| 现有 browse stub 载荷未补新字段导致前端测试大面积红 | 阶段 D2 已列出全部 4 处；执行时先改 payload helper再跑测试 |

| Windows 受保护目录 stat 抛 OSError | `_iter_entries` 单条目 try/except OSError 跳过（沿用现防御） |
