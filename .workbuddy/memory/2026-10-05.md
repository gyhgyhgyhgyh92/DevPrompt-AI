### 踩坑记录（审查脚本自身缺陷，非数据问题）
1. `Path.parents[3]` 多退一级 → 读到 `D:\`，应 `parents[1]`
2. **`git grep -E` 不支持 lookbehind 断言**（`(?<!\w)`）→ 100/100 误报"仓库内找不到符号"。改用 `-F` 固定串 + Python 侧词边界
3. TS 泛型签名 `export function skipHydrate<T = any>(` 未被正则覆盖 → 误报 12 条，正则需加 `(?:<[^>]*>)?`
4. 以"首个命中文件"判路径归属是错误判据（git grep 顺序与标注无关）→ 改为"`expected_path` 是否在命中集合内"
5. `SymbolTableResult` 字段是 `symbols` 不是 `table`
6. `SymbolTableProvider(runner)` 必填参数，需注入 `LocalCommandRunner()`

> 第2、3 条若不修正，会得出「100 条符号全部不存在」的错误结论。教训：审查工具本身必须先自证可靠。
