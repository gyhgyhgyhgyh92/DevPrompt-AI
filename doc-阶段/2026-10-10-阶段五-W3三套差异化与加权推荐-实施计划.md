### 5B · ranking 纯函数域层（T5-4/T5-5/T5-6）

**SMART 目标**：Specific=四维偏好/匹配度/加权总分/双阈值推荐四组纯函数；Measurable=新增单测 ≥25 用例（含 SHOULD-10 手工验算 + MUST-27 四情形），全绿；Achievable=零 I/O 纯函数；Relevant=F-402~F-404 直接规格；Time-bound=W1 内。

**步骤**（TDD：每模块先红后绿）：

1. **第一** `domain/ranking/ports.py`：
```python
VariantFeatures: TypeAlias = dict[Literal["detail_level","include_diff","specify_tests","max_files_norm"], float]
class PreferenceStore(Protocol):  # MUST-06 落点：实现在 memory/preference_store.py
    async def load(self, user_id: str) -> dict[str, float]: ...
    async def save(self, user_id: str, vector: dict[str, float]) -> None: ...
    async def record_adoption(self, rec: AdoptionRecord) -> None: ...
```
2. **第二** `preference.py`：`FEATURE_TABLE`（**以功能清单 F-402 原文为准的分维值——执行期核对发现计划初稿「0.25/0.58/1.0」仅是 max_files_norm 单行值，实际为分维不同值：detail_level 0.3/0.6/0.9、include_diff 0.5/0.8/0.9、specify_tests 0.2/0.5/0.8、max_files_norm 0.25/0.58/1.0，已按原文实现并附溯源断言（D-5B-1 裁决，2026-10-10）**）；`match_score(pref, feat) = 1 - mean(|pref_i - feat_i|)`；`clip01`。
3. **第三** `score.py`：`weighted_total(适配度, 匹配度, w_fit=0.6, w_pref=0.4)`；`validate_weights(w1, w2)`（和 ≠1.0 → ConfigError 9002）。**手工验算测试**：`(0.8,0.7)→0.76`、`(0.25,0.9)→0.51` 等固定断言。
4. **第四** `recommend.py`：`RecommendationResult`（variant/gap/confidence/marked/reason）；`decide_mark(scores: list[VariantScoreView])`——MUST-27 五条**优先级顺序、命中即止**：①top conf<0.6→不标（Jev 置信度不足）②任一档 conf<0.4→不标 ③d<0.12→不标（三套接近）④d≥0.5→标 ⑤0.12≤d<0.5→标+「分差较小」；每条不标必给具体 reason 文案。**四情形测试各一例** + 优先级压序测试（同 satisfy 多条时先到先得）。
5. **第五**：门禁（ruff/mypy/pytest/架构检查——ranking 禁 import 基础设施）+ 提交。

**边界**：起=空文件；止=纯函数全绿；不做 L3 存储（5D）、不接 service（5F）。**验收**：25 用例全绿；MUST-27 五条覆盖有测试 id 溯源。

### 5C · 三套生成扩展（T5-1/T5-2）
